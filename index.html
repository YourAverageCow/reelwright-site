Reelwright

Stories in. Films out.

Reelwright is a desktop application that turns a written story into a finished vertical short video: it writes or accepts a story, narrates it with a text-to-speech voice, burns word-timed captions over a background clip, and renders an MP4. It runs locally on the user's own computer; there is no Reelwright server and no account.

What it does with YouTube

Optionally, Reelwright can upload the videos it renders to a YouTube channel that the user owns. That is the only use of YouTube data:

  • It asks for permission to upload videos to the user's channel and to read the channel's basic details (name and avatar) so the rendered title card can match the channel.
  • An upload happens only when the user presses Publish on a finished video, or enables automatic publishing for a batch they started. Nothing is uploaded in the background.
  • It reads nothing else from YouTube: no watch history, no subscriptions, no comments, no other channels' data.

Where data lives

Everything stays on the user's computer. Stories, audio, renders and OAuth tokens are stored in the application's own local data folder, readable only by the user. Reelwright has no backend and sends nothing to its author.
